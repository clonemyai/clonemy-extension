Send a capsule to your phone

Scan the code below with your phone. Its browser opens the clonemy shuttle with the code already filled in; tap Connect there, and this page names the capsule and waits. Nothing moves until the phone accepts the named offer, and the capsule crosses directly between this browser and the phone. Keep this tab open until the transfer finishes.

No camera? On the phone, open clonemy.ai/shuttle.html and type the six characters instead. The code works once and dies ten minutes from when it appeared.

What crosses where: the file travels straight between the two browsers, encrypted in transit by WebRTC, and is never stored on a server. A public rendezvous service, the PeerJS broker, matches the code to the two browsers; it can see the code, both IP addresses, and the time, and it cannot see the file.
